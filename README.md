# 바이브 레벨 테스트 · 예비용 (일반 호스팅 + 구글 시트 저장)

앱스크립트 웹 앱 주소가 열리지 않을 때(구글 계정이 여러 개 로그인된 브라우저 등) 쓰는 **예비용**입니다.
화면, 문항, 채점, 교사 화면, 구글 시트 저장과 `요약 그래프`는 앱스크립트 버전과 똑같습니다.

| | 앱스크립트 버전 (`vibe-level-test-gas`) | 예비용 (이 폴더) |
|---|---|---|
| 화면이 열리는 곳 | `script.google.com/…/exec` | Netlify 같은 일반 웹 주소 |
| 앱스크립트가 하는 일 | 화면 + 저장 | 저장만 |
| 구글 계정 여러 개 로그인 | 안 열릴 수 있음 | **상관없이 열림** |

| 파일 | 넣을 곳 |
|---|---|
| `Code.gs` | **새** 구글 시트의 앱스크립트 편집기 (HTML 파일은 넣지 않음) |
| `index.html` | 맨 위 `API_URL`에 주소를 넣은 뒤 웹 호스팅에 올림 |

## 1단계: 저장 서버 만들기 (구글 시트 + 앱스크립트)

1. 개인 Gmail 계정으로 **새 구글 시트**를 만듭니다. (기존 앱스크립트 버전 시트와 따로)
2. **확장 프로그램 → Apps Script**를 열고, `Code.gs` 내용을 지운 뒤 이 폴더의 `Code.gs`를 붙여 넣습니다.
   - HTML 파일(`index`)은 **만들지 않습니다.**
3. 저장한 뒤 함수 목록에서 `setup`을 고르고 **실행**합니다. 권한 승인: **고급 → (안전하지 않음)으로 이동 → 허용**
4. **배포 → 새 배포 → 웹 앱**을 고르고 아래처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 나온 웹 앱 URL(`…/exec`)을 복사합니다.
   - 확인: 이 주소를 시크릿 창에서 열었을 때 `"ok":true … 저장 서버가 동작 중이에요` 글이 보이면 성공입니다.

## 2단계: 화면 파일에 주소 넣기

`index.html`을 메모장(또는 VS Code)으로 열고, 위쪽의 이 줄을 찾아 따옴표 안에 1단계 주소를 붙여 넣고 저장합니다.

```js
var API_URL = "https://script.google.com/macros/s/……/exec";
```

## 3단계: 웹 호스팅에 올리기 (Netlify 예시)

1. 새 폴더를 하나 만들고 `index.html`만 넣습니다. 파일 이름은 반드시 `index.html`이어야 합니다.
2. https://app.netlify.com 에 **무료 가입**합니다. 구글 계정으로 가입할 수 있습니다.
   - 가입하지 않고 올리면 사이트가 잠깐 뒤에 지워질 수 있으니, 가입한 상태에서 올리세요.
3. **Add new site(또는 Add new project) → Deploy manually**를 눌러 폴더를 끌어다 놓습니다.
4. 생긴 주소(`https://○○○.netlify.app`)가 참여자 주소입니다.
   - 사이트 설정에서 주소 앞부분 이름을 `vibe-test-2026`처럼 바꿀 수 있습니다.

## 3단계 대신: GitHub Pages에 올리기

1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+ → New repository**를 누릅니다.
   - 이름 예: `vibe-test`
   - **Public**을 고릅니다. 무료 계정의 GitHub Pages는 공개 저장소만 됩니다.
   - **Create repository**를 누릅니다.
3. 저장소 화면의 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누르고 `index.html`을 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
4. 저장소 **Settings → Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://아이디.github.io/vibe-test/`
   - 이 주소가 참여자 주소이고, 교사 화면은 `https://아이디.github.io/vibe-test/?teacher`입니다.

**고칠 때:** 저장소에서 `index.html`을 누르고 ✏️(연필)로 직접 고치거나, **Add file → Upload files**로 새 파일을 다시 올립니다. 1~2분 뒤 반영됩니다. 바로 안 바뀌면 새로 고침(Ctrl+F5)을 해 보세요.

> 공개 저장소라서 `index.html` 안의 문항과 `API_URL` 주소는 누구나 볼 수 있습니다. Netlify에 올려도 페이지 소스에서 보이는 것은 마찬가지입니다. 응답 데이터는 구글 시트에만 있고, 이름과 점수는 교사 화면을 여는 사람이면 볼 수 있습니다.

> tiiny.host 같은 다른 정적 호스팅도 `index.html` 하나만 올리면 똑같이 동작합니다.

## 주소

- 참여자: `https://○○○.netlify.app` (회차를 나누려면 `?r=1기`)
- 교사 화면: `https://○○○.netlify.app/?teacher` (회차가 있으면 `?teacher&r=1기`)
- 첫 화면의 **교사 화면으로 가기** 링크로도 들어갈 수 있습니다.

## 고칠 때

- **문항이나 화면을 고치면**: `index.html`을 고친 뒤 Netlify의 **Deploys** 탭에 폴더를 다시 끌어다 놓습니다. 주소는 그대로입니다.
- **`Code.gs`를 고치면**: **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 합니다. 주소는 그대로입니다.
- 문항을 바꾸면 `index.html`의 `Q`와 `Code.gs`의 `Q_LABELS`, `Q1_OPTS`를 함께 맞춰 주세요.

## 문제가 생기면

- 첫 화면에 **노란 '데모 모드' 안내**가 보이면 `API_URL`이 비어 있거나 `https://`로 시작하지 않는 것입니다.
- 결과 화면에 **"응답을 보내지 못했어요"**가 뜨면 `API_URL` 주소가 `/exec`로 끝나는지, 배포 액세스가 **모든 사용자**인지 확인하세요.
- 시트 `응답` 탭, `요약 그래프` 탭 사용법은 앱스크립트 버전과 같습니다.
